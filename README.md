# Portafolio

Sitio de una sola página con mis proyectos web. Hecho con HTML, CSS y JavaScript, sin dependencias.

## Cómo editarlo

Todo el contenido está en `datos.js`: nombre, usuario de GitHub, correo, textos y la lista de proyectos. No hace falta tocar los demás archivos.

Para poner la captura de un proyecto, guárdala en `img/` y escribe su ruta en el campo `imagen` (por ejemplo `"img/netflix.jpg"`).

## Verlo

- En local con XAMPP: `http://localhost/portafolio/`
- Publicado: GitHub Pages (Settings → Pages → rama `main`).
